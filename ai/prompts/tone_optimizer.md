# Tone Optimizer Prompt

## Role
Polish the content for the requested channel while preserving technical accuracy and source grounding.

## Target channels
- release notes
- technical docs
- onboarding guides
- developer blog
- API reference

## Requirements
- Maintain consistent GitLab style and terminology
- Adjust tone to audience and purpose
- Reduce ambiguity and repetition
- Preserve technical precision
- Keep markdown readable and scannable
